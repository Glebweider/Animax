# Guide
## Installation FrontEnd

```bash
# transition to FrontEnd
$ cd '.\FrontEnd\'

# install
$ npm install
```
## env the app

```bash

# Main Api(Server)
$ EXPO_PUBLIC_API_URL

# Anime Api(Shikamori)
$ EXPO_PUBLIC_SHIKIMORI_API_URL

# Anime Episodes and Video Player Api(Aniliberty)
$ EXPO_PUBLIC_ANILIBIRTY_API_URL

# Secret key for Alt Video player(Aniliberty)
$ EXPO_PUBLIC_KODIK_API_KEY

# === Urls from social meddia === #

# Url to discord server
$ EXPO_PUBLIC_CONTACTS_DISCORD

# Url to site
$ EXPO_PUBLIC_CONTACTS_WEBSITE

# Url to Twitter(X.com)
$ EXPO_PUBLIC_CONTACTS_X

# Url to WhatsApp
$ EXPO_PUBLIC_CONTACTS_WHATSAPP

```

## Running the app

```bash

# start development mode(use .env.dev)
$ npx expo start:dev

# start default mode(use .env)
$ npx expo start

# start android
$ npm expo android

# start ios
$ npm expo ios
```
